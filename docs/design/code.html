1. How to use

3 STEPS
  1. Draw glyphs: Select letters in the left tray and sketch them onto the canvas with your pen, tablet, or mouse.
  2. Test live preview: Type sample sentences in PREVIEW.TXT to inspect line height and kerning rhythms.
  3. Export your font: Hit "Download .otf" to produce standard true OpenType files.

2. Installation

ANY OS
Mac / Windows:

Double-click the downloaded .otf file and select "Install Font" in your system Font Book or Control Panel.

iPad / Canva / GoodNotes:

Upload the .otf file directly into your Canva Brand Kit, Procreate font folder, or use the iFont iOS profile installer.
